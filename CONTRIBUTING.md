# Cómo aportar

## Pedir un juego
Abre un Issue con la plantilla **"Pedir un juego"**. Antes, busca si ya está pedido y vota con 👍.

## Aportar una receta
1. Copia [`recipes/nfs-most-wanted-2005.yaml`](recipes/nfs-most-wanted-2005.yaml) como plantilla.
2. Llénala con lo que probaste: tu Mac, tu versión de macOS, qué funcionó y qué no.
3. Abre un pull request.

Una receta vale aunque el resultado sea "no funciona": saber qué falla ahorra horas a otros.

## Reglas (no negociables)
- **Nada de archivos de juegos** ni enlaces o instrucciones para conseguirlos. Solo copias que el usuario tiene legalmente.
- **Nada de software de terceros dentro del repo.** Los scripts descargan Wine, el Game Porting Toolkit o las recompilaciones desde sus fuentes oficiales.
- **Da crédito** a los proyectos que uses.
- Las huellas (SHA-256) de ejecutables sí se pueden publicar: identifican una versión sin distribuir el archivo.
